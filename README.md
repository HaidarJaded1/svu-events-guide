# دليل فعاليات الجامعة الافتراضية

مشروع مادة BWP401 لعرض الفعاليات الجامعية وتصنيفاتها وتفاصيلها.

التقنيات المستخدمة: HTML، CSS، JavaScript، Bootstrap 5.3.3.

صفحات الموقع:

- الرئيسية
- الفعاليات
- تفاصيل الفعالية
- عن الدليل
- اتصل بنا

يعمل الموقع بفتح ملف `index.html` في المتصفح، مع اتصال بالإنترنت لتحميل Bootstrap وخط Cairo.

الفعاليات الحالية بيانات تجريبية.

يمكن تبديل الوضع الداكن من زر القمر في زاوية الصفحة. يتبع الموقع إعداد الجهاز افتراضياً، ويحفظ اختيار المستخدم عند توفر التخزين المحلي. يظهر زر العودة إلى الأعلى عند تمرير الصفحة، ويحترم إعداد تقليل الحركة في المتصفح.
